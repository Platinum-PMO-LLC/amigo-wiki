# Introduction

<p align="justify">We have a mechanism in AMIGO known as a Work Package Type, which we will use to categorize the Work Packages we want to create for our Projects or Programs.</p>

## Key Relationship

![WorkPackageType](https://github.com/Platinum-PMO-LLC/amigo-wiki/assets/85743317/f573288e-adff-44e6-9289-7ab5bb7c4576)

Object | Usage Notes | Visibility | Filter & Search Criteria
-- | -- | -- | --
Organization | Modifications to the Organization record will be reflected in the Work Package Type | Users invited to the Organization record will gain access to the specific Work Package Type | [Organization](https://platinum-pmo-llc.github.io/amigo-wiki/Organization-(Detail-Page))
Portfolio | Modifications to the Portfolio record will be reflected in the Work Package Type | Users invited to the Portfolio record will gain access to the specific Work Package Type | [Portfolio](https://platinum-pmo-llc.github.io/amigo-wiki/Portfolio-(Detail-Page))
Deliverable Type | Modifications to the Deliverable Type record will be reflected in the Work Package Type | The users invited to the associated Organization and Portfolio record will have access to the particular Work Package Type | [Deliverable Type](https://platinum-pmo-llc.github.io/amigo-wiki/Deliverable-Types-(Detail-Page))
