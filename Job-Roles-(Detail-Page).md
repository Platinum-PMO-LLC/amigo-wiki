### Security Profile 
When setting up a job role the security profiles to all the different applications that that job role needs to perform and fulfill what they need to do for the organization. A Job Role can have many Security Profiles and Security Profiles could be assigned to many different job roles. So, to associate Security Profiles with Job Roles, the Security Profile button is used. When a user clicks on it, a form layout will open, which has some details which are needed to fill in and click Save. Thus Security Profile gets associated with the Job Role.
