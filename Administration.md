# 🔧 Administration

> Platform setup and configuration capabilities within the AMIGO platform.

---

## 📖 Overview

The Administration module in AMIGO provides comprehensive functionality for configuring and managing the platform. From defining deliverable types to setting up approval workflows, AMIGO ensures proper platform governance and customization.

---

## 📋 Administration Objects

### Configuration Objects

| Object | Description |
|--------|-------------|
| [Deliverable Types](https://platinum-pmo-llc.github.io/amigo-wiki/Deliverable-Types-(Detail-Page)) | Categories for deliverables (reports, interfaces, etc.) |
| [Work Package Types](https://platinum-pmo-llc.github.io/amigo-wiki/Work-Package-Types-(Detail-Page)) | Standard work package categories per deliverable type |
| [CFG Approval](https://platinum-pmo-llc.github.io/amigo-wiki/CFG-Approval-(Detail-Page)) | RACI chart approval configuration rules |

```text

       ↓

```

## 💼 Business Usage

### PMO Application

Administration in AMIGO supports the critical platform setup and ongoing maintenance activities essential for effective program management. By providing comprehensive configuration options, administrators can tailor AMIGO to their organization's specific needs and methodology.

### Common Use Cases

- **Platform Setup**: Configure deliverable types and work package types for your methodology
- **Approval Workflows**: Define RACI-based approval rules for governance activities
- **Knowledge Management**: Maintain insights and accelerators to guide users
- **User Onboarding**: Add and configure users with appropriate access
