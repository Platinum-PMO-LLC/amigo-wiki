## 💼 Business Usage

### PMO Application

Resources represent the people assigned to work on program activities. AMIGO tracks resource allocation, availability, and utilization to support capacity planning and workload balancing across workstreams.

### Common Use Cases

| Use Case | Description |
|----------|-------------|
| **Team Assignment** | Assign people to workstreams and projects |
| **Capacity Planning** | Balance workload across resources |
| **Skill Matching** | Align skills with work requirements |
| **Utilization Tracking** | Monitor resource usage |
| **Conflict Resolution** | Identify over-allocation |

### Resource Attributes

- **Name**: Resource identifier
- **Role**: Job function or title
- **Workstream**: Primary assignment
- **Allocation %**: Percentage of time allocated
- **Availability**: Start and end dates
- **Skills**: Competencies and certifications

### Resource Management Process

1. **Demand** - Identify resource requirements
2. **Supply** - Assess available resources
3. **Assign** - Match resources to work
4. **Track** - Monitor utilization
5. **Optimize** - Rebalance as needed
