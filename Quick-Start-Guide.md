# 🚀 Quick Start Guide

> Get up and running with AMIGO in 5 minutes

---

## 📋 Prerequisites

Before you begin, ensure you have:

- [ ] Salesforce user account with AMIGO access
- [ ] Assigned to an Organization within AMIGO
- [ ] Appropriate permission set assigned by your administrator

---

## 🎯 Step 1: Access AMIGO

1. **Log into Salesforce** at [amigo.my.salesforce.com](https://amigo.my.salesforce.com)
2. **Navigate to AMIGO** using the App Launcher (9-dot grid icon)
3. **Select "AMIGO"** from the application list

---

## ⭐ Step 3: Set Up My Favorites

Bookmark frequently used objects for quick access:

1. Navigate to any object (e.g., Projects)
2. Click the **star icon** ⭐ next to the object name
3. Access favorites from the **Favorites** menu in the navigation bar

---

## 🔔 Step 4: Configure Notifications

Stay informed about changes that affect your work:

1. Click your **profile icon** in the top-right corner
2. Select **Settings** > **Custom Notifications**
3. Choose which events trigger notifications:
   - Assigned as Responsible
   - Assigned as Accountable
   - Mentioned in comments
   - Work package status changes

---

## 📝 Step 5: Understand Key Concepts

### The AMIGO Hierarchy

```text
Organization
    └── Portfolio
        └── Program
            └── Project
                └── Deliverable
                    └── Work Package
```

### RACI Matrix

Every element in AMIGO uses RACI for accountability:

| Letter | Role | Description |
|--------|------|-------------|
| **R** | Responsible | Does the work |
| **A** | Accountable | Approves the work |
| **C** | Consulted | Provides input |
| **I** | Informed | Kept in the loop |

### AI Messenger

AMIGO's intelligent notification system automatically alerts relevant team members when:
- Work packages are created or updated
- Objects they're working on are affected by changes
- Approvals are needed
- Issues or risks impact their deliverables

---

## ✅ Step 6: Complete Your First Tasks

### View Your Assignments

1. Navigate to **My Messages** to see notifications
2. Check **Work Packages** assigned to you
3. Review any **Action Items** in your queue

### Update a Work Package

1. Navigate to your assigned Work Package
2. Click **Edit** to update status or details
3. Add comments to communicate progress
4. Save your changes

### Log Time (if enabled)

1. Navigate to **Time Reports**
2. Create a new Time Report for the current week
3. Add **Time Tracking Details** for each work package
4. Submit for approval
