## 💼 Business Usage

### PMO Application

The Communications Register centralizes all stakeholder communications planning, ensuring the right information reaches the right people at the right time. It defines communication frequency, channels, and responsible parties for consistent stakeholder engagement.

### Common Use Cases

| Use Case | Description |
|----------|-------------|
| **Stakeholder Updates** | Define regular status reporting cadence |
| **Executive Briefings** | Schedule steering committee communications |
| **Team Announcements** | Plan internal team communications |
| **External Communications** | Manage vendor and client updates |
| **Change Notifications** | Communicate approved changes to affected parties |

### Communication Planning Elements

- **Audience**: Who needs to receive the communication
- **Frequency**: How often (daily, weekly, monthly, ad-hoc)
- **Channel**: Email, meeting, report, dashboard
- **Owner**: Who is responsible for the communication
- **Content**: What information to include
