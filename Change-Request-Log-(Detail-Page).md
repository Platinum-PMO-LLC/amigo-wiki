## 💼 Business Usage

### PMO Application

The Change Request Log in AMIGO provides robust change control for managing scope modifications throughout the program lifecycle. Given that significant budget often flows through change requests, AMIGO implements a comprehensive approval workflow to ensure proper governance.

### Common Use Cases

- **Scope Changes**: Document requests to add, modify, or remove scope items
- **Budget Impact**: Track financial implications of proposed changes
- **Impact Assessment**: Link to affected business transactions and systems
- **Approval Workflow**: Route through RACI-based approval process
- **Issue Integration**: Connect change requests originating from logged issues

### Change Control Process

| Stage | Description |
|-------|-------------|
| **Request** | Document the proposed change with justification |
| **Assess Impact** | Evaluate effects on scope, schedule, budget, and quality |
| **Review** | Present to change control board or governance body |
| **Approve/Reject** | Make formal decision with documentation |
| **Implement** | Execute approved changes with tracking |
| **Close** | Verify implementation and close request |

### Key Features

- **Change Request Types**: Categorize by type (scope, schedule, budget, etc.)
- **System Impact**: Link to affected systems for technical assessment
- **Object Linkage**: Connect to impacted objects for traceability
- **Financial Tracking**: Document cost and benefit implications
- **Approval History**: Maintain audit trail of all decisions
