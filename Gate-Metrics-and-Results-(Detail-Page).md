## 💼 Business Usage

### PMO Application

Gate Metrics and Results define the specific criteria that must be satisfied to pass a gate review. They provide objective, measurable evidence of readiness and ensure consistent evaluation across all gate reviews.

### Common Use Cases

| Use Case | Description |
|----------|-------------|
| **Testing Completion** | X% test cases passed, Y critical defects resolved |
| **Documentation Sign-off** | All required documents approved |
| **Training Completion** | Z% of users completed training |
| **Performance Benchmarks** | System meets response time requirements |
| **Risk Acceptance** | All high risks mitigated or accepted |

### Metric Types

- **Quantitative**: Measurable numbers (%, counts, scores)
- **Qualitative**: Yes/No completion status
- **Evidence-Based**: Document or artifact existence
- **Approval-Based**: Required sign-offs obtained

### Result Recording

| Result | Description |
|--------|-------------|
| **Met** | Metric fully satisfied |
| **Partially Met** | Metric partially satisfied with conditions |
| **Not Met** | Metric not satisfied |
| **N/A** | Metric not applicable to this gate |
