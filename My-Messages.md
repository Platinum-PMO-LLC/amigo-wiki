# 💬 My Messages

> AMIGO's AI Messenger communication hub for notifications, alerts, and direct messages

---

## 📖 Introduction

My Messages is the central communication hub within AMIGO that displays all notifications, alerts, and messages generated by the AI Messenger system. It connects team members across the program by automatically alerting users when changes occur that may impact their work.

---

## 🔗 Schema

```text
AI Messenger System
    ├── System Notifications (automated)
    ├── AI Alerts (impact-based)
    ├── Direct Messages (user-to-user)
    └── Approval Requests (workflow-based)
           ↓
    My Messages (User Inbox)
           ↓
    Read/Unread Status → Actions
```

---

## 📋 Message Types

### System Notifications

Automated alerts triggered by system events:

| Trigger | Description |
|---------|-------------|
| Record Assignment | You've been assigned as R, A, C, or I |
| Status Change | A record you're involved with changed status |
| Due Date Alert | Upcoming or overdue items |
| Approval Required | Items awaiting your approval |

### AI Messenger Alerts

Intelligent notifications based on impact analysis:

| Alert Type | Description |
|------------|-------------|
| Object Impact | Changes to objects that affect your deliverables |
| Dependency Alert | Predecessor/successor changes |
| Risk/Issue Escalation | New risks or issues affecting your work |
| Cross-Team Impact | Changes from other workstreams affecting you |

### Direct Messages

User-to-user communications within AMIGO:

| Feature | Description |
|---------|-------------|
| @Mentions | Tag users in comments |
| Thread Replies | Respond to specific messages |
| File Attachments | Share documents in messages |

### Approval Requests

Workflow-based notifications for RACI approvals:

| Request Type | Action Required |
|--------------|-----------------|
| Work Package Approval | Review and approve/reject |
| Deliverable Sign-off | Validate completion |
| Change Request | Approve scope changes |
| Time/Expense | Approve submissions |

## ⚙️ Available Features

### Viewing Messages

1. Click **My Messages** in the AMIGO navigation
2. Messages display in reverse chronological order
3. Unread messages are highlighted
4. Click a message to view details

### Filtering Messages

Filter messages by:

| Filter | Options |
|--------|---------|
| **Status** | Read, Unread, All |
| **Type** | System, AI Alert, Direct, Approval |
| **Date Range** | Today, This Week, Custom |
| **Priority** | High, Medium, Low |
| **Related Object** | Project, Deliverable, Work Package, etc. |

### Mass Update

Perform bulk actions on messages:

1. Select multiple messages using checkboxes
2. Choose action:
   - **Mark as Read**
   - **Mark as Unread**
   - **Archive**
   - **Delete**
3. Click **Apply**

### Message Actions

Actions available for each message:

| Action | Description |
|--------|-------------|
| **View Related** | Navigate to the related record |
| **Reply** | Respond to the message |
| **Forward** | Share with another user |
| **Archive** | Remove from inbox |
| **Delete** | Permanently remove |

## 🔔 Notification Configuration

### Setting Preferences

1. Click your **Profile** icon
2. Select **Settings** > **Notification Preferences**
3. Configure for each notification type:

| Setting | Options |
|---------|---------|
| **In-App** | Show in My Messages (always on) |
| **Email** | Send email notification |
| **Push** | Mobile push notification |
| **Digest** | Daily summary email |

### RACI-Based Notifications

Configure notifications based on your RACI role:

| RACI Role | Default Notifications |
|-----------|----------------------|
| **Responsible** | All changes to assigned items |
| **Accountable** | Approval requests, status changes |
| **Consulted** | Requests for input |
| **Informed** | Status updates, completions |

## 💼 Business Usage

### PMO Application

My Messages supports critical communication activities:

- **Real-Time Awareness**: Know immediately when your work is affected
- **Cross-Team Coordination**: AI Messenger connects dependent teams
- **Audit Trail**: All communications are logged and traceable
- **Reduced Email Overload**: Consolidated in-app notifications

### Common Use Cases

- **Morning Check-In**: Review overnight notifications
- **Impact Assessment**: Understand how changes affect your deliverables
- **Approval Processing**: Handle pending approvals efficiently
- **Team Collaboration**: Communicate within the context of work items

### AI Messenger Intelligence

The AI Messenger analyzes the AMIGO object model to:

1. **Identify Dependencies** - Find connected work packages and deliverables
2. **Map Impact** - Determine who needs to know about changes
3. **Prioritize Alerts** - Highlight critical notifications
4. **Suggest Actions** - Recommend next steps

## 🛡️ Best Practices

### Managing Message Volume

- Configure notification preferences to reduce noise
- Use filters to focus on high-priority items
- Archive processed messages regularly
- Set up digest emails for low-priority notifications

### Response Time Guidelines

| Message Type | Recommended Response |
|--------------|---------------------|
| Approval Requests | Within 24 hours |
| High-Priority Alerts | Same day |
| Direct Messages | Within 48 hours |
| Informational | As needed |
