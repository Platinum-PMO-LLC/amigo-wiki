## Available features
### Highlights Panel
To enhance key relationship management within the AMIGO platform, we've implemented the following features for designated high-priority relationships during System assignment.

The attached image showcases the Highlights Panel on the System record page. This panel provides action buttons that enable users to efficiently associate the System with its relevant objects.

![image](https://user-images.githubusercontent.com/85743317/184690573-7dc7dbdf-40d8-4aa8-a473-e10aa302552d.png)

### RACI Chart
<p align="justify">The user may want to find some ownership of who's going to make the decisions around a given System, whether it's in scope, out of scope, or when it's going to be retired. And so he wanted to find who's responsible, who's accountable, who needs to be consulted, and who needs to be informed about every system that is documented. Using the `RACI Chart` button this purpose is served.</p>

### Approvals
When the user wants to define the Approval Processes and who's going to be signing off on the disposition of those systems, the `Approvals` button can be used to perform, this action. Typically, it's hand in hand with the RACI chart. The Approvals button feature progresses only when the RACI Chart is assigned.
To learn about the `RACI Chart` feature, please [click here](https://platinum-pmo-llc.github.io/amigo-wiki/RACI-Chart).

### Add Data Table
When the user/s is gonna define all the tables associated with those systems, also known as your database that is using the system, then using the `Add Data Table` button the action can be performed. 

### Edit
The Edit function allows users to modify existing records as needed.

### Delete
The Delete button is to delete the record as per the user's wish.
