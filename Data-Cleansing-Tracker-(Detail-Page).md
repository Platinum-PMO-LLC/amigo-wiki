## Available features

The following features have been implemented for associating the key relationships of Data Cleansing Tracker within the AMIGO platform. The below image shows the Highlights Panel of the record page of the Data Cleansing Tracker, where the action buttons are present, which acts as the medium for serving the above-mentioned purpose.

![image](https://user-images.githubusercontent.com/85743317/184822134-f498e8c5-2d7d-4562-b398-bfd6410f2af1.png)

### Data Cleansing Tracker Metrics
The data cleansing tracking metrics are associated with Data Cleansing Tracker as a key relationship. And these are the detailed metrics and what it needs. What you need to do and what needs to be cleaned in order to complete the data cleansing tracking element. Now, the data cleansing tracker can have many tracking metrics. However, a tracking metric can be associated with one, and only one data cleansing tracker. Using the `Data Cleansing Tracker Metrics` button the above mention action can be performed.

### RACI Chart
Using the `RACI Chart`, users can define who's responsible, who is accountable, who needs to be consulted, and who needs to be informed on your data cleansing efforts.

### Take Action
Once the RACI members have been added successfully, the user can send the Data Cleansing Tracker for Approval by respective RACI members, by clicking on the `Take Action` button.
